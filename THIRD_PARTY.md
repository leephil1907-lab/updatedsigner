## Upstream execution branding

This interface references upstream brand marks for connected capability surfaces. These are displayed as attribution/identification for the integrations and are not presented as ownership of the upstream projects.

- Dify — upstream: https://github.com/langgenius/dify — Dify Open Source License (Apache 2.0 based with additional conditions, including frontend logo/copyright requirements). The interface uses the upstream Dify site logo asset.
- Firecrawl — upstream: https://github.com/firecrawl/firecrawl — primarily AGPL-3.0; SDKs and some UI components have separate licenses. The interface references the upstream Firecrawl logo asset.
- Browser Use — upstream: https://github.com/browser-use/browser-use — the interface references its upstream logo artwork for identification.
- Orca — upstream: https://github.com/stablyai/orca — MIT; the interface references the upstream icon asset.
- WOW-Agent, Jev and Delta are represented by text wordmarks where a suitable upstream logomark/license basis was not established, rather than inventing or copying a mark without verification.

The product remains responsible for complying with each upstream project's trademark and asset-use requirements.
